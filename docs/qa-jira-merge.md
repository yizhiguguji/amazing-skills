# 已安装导出中的 QA/Jira 改进合并

日期：2026-10-15。来源为另一台电脑导出的 0.5.0、14 技能 installed export（2026-10-15），仅取其中自有 QA/Jira 文档，不复制旧可执行文件、目录快照、上游提供者或配置。本仓库继续为 0.6.0，保留 15 技能、工作台 9 技能及设计闭环；Go 1.27.2、标准库约束不变。

## 采纳与适配

- qa-test-design：区分首次设计、需求变更、文字修订与复审；强调独立测试目标、可定位数据变体、执行可读性、拆合观察映射以及历史保留。新增 case-review 引用，不新增技能层级。
- 本地契约补充：已冻结内容的文字变更同样增加 revision，不能用语义等价绕过 Go 冻结检查；新修订不继承旧执行通过。既有系统保持自己的版本机制。
- Jira：异常与补充观察分开，多项预期清楚表达，无附件不生成空证据段。颜色、加粗、编号、执行者披露与目标平台富文本按实际项目决定；不把默认深红或不提执行方式变成通用规则，模拟来源和必要限制不得隐去。
- Go Draft：expected 向后兼容字符串，扩展为非空字符串数组；可选 observations 为非空字符串数组。多行列表项正确缩进；无附件时回执 evidence_count=0、evidence_status=not-attached，正文没有空证据区。媒体存在时标 local-only，不宣称上传。
- 历史：已存在草稿仅允许相同内容重用；旧格式精确匹配相同输入时保留原正文与 hash 并返回 legacy-preserved，其他碰撞拒绝写入。格式升级使用新修订，不自动覆盖旧记录。

## 验证范围

Go 回归覆盖空/有证据、字符串/多项预期、补充观察、无效输入、旧正文及摘要保留、文字修订冻结与旧通过隔离。全量测试继续覆盖安装迁移、QA 历史与 0.6.0 设计包/预览/设计锁。另用新编译程序的可移动安装在无 Go/Python/Node 的 PATH 中检查 Jira 新行为与设计闭环。

语义评审说明：订单价格/币种/税额可共同验证同一个目标；展示、支付授权、退款若独立判定则分别成例。文字修订不重新展开全产品矩阵。这些例子解释方法，不替真实项目决定范围；没有宣称模型已在所有需求上做出正确拆合。

本次未提交外部 Jira、未安装依赖、未覆盖本机已安装技能。无 UI 变更，沿用既有浏览器视觉证据，重新运行包同步及设计锁检查；未重测真实 Jira 富文本显示、真实设备或其他操作系统。
