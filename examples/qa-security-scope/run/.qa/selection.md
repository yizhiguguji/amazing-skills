# 模拟请求的技能选择

目标：通用技能两层能力在本合成昵称需求上验证范围、未知预期、执行边界与历史维护；所有测试模型和来源均为合成，不是实际系统安全结论。

r1“帮我出用例，看看安全”：qa-test-design筛选本期昵称保存、归属和预览；范围外的头像、上传、支付、密码重置不纳入。会话规则未知，保留proposed和G1，不编造30分钟或401。

r2“长度改了，预览不要了”：qa-test-design修订TC-001/002，TC-004保留retired，TC-003/005保持。安全候选、目标和依据跟随需求版本，旧通过不继承。

专项阶段“安全再仔细看看”：qa-security-review仅对同一昵称模型审查/验证；AUTH-1确认目标和合成动作后执行有限复测。缺授权的正式执行记录被拒绝。没有真实请求、扫描、外部建单或设备操作。

qa-test-report复算当前轮次和历史失败；qa export-cases导出安全来源/范围。Jira未选择，因为请求只要求模拟验证，没有真实外部提交。

这是维护AI的语义选择记录，Go回放验证计划和证据约束；不是独立AI评测或关键词路由程序。
