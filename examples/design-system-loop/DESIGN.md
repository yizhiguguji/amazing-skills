# 续读设计规范

## 方向

来自 sources/request.md 的合成抽象意图：安静，并能找到下一次阅读的起点。暖色纸面和衬线标题是可撤销推断，不是客户确认。以 calm-paper 自建合成包起步，不复制外部品牌。

## 排版与颜色

精确值由 tokens.css 管理；背景、文本、辅助文本、强调色与错误消费 --ds-bg、--ds-fg、--ds-muted、--ds-accent、--ds-danger。正文与标题使用 --ds-font-body / --ds-font-display 中的中文回退；不加载外部资源。

## 布局与密度

桌面采用连续列表配侧边输入，避免卡片堆叠；小屏先呈现阅读列表，再呈现新增操作。长标题换行，列表能在放大字体后继续阅读。空间使用 --ds-space 的倍数；按钮高度使用 --ds-control。

## 组件与状态

冷启动没有假书目或数字；给出添加入口。保存显示输入错误与本地反馈，记录下一步时保持书名。列表以真实本地记录计算，删除以明确书名命名；存储失败显示错误，不伪装保存成功。组件预览中的数据明确为合成，不作为应用初始数据。

## 交互与响应式

Tab 能到达表单和操作，焦点可见；新增成功后清空表单并回到书名，恢复阅读依据记录内容。无必要动效。桌面与小屏实际渲染需独立验收；组件预览不能替代应用检查。

## 实现与接续

index.html 直接 link tokens.css，styles.css 使用变量，无第二套主题值；变更前后使用 project check-design，设计锁保护 DESIGN.md 与 tokens.css。产品依据为 .workbench/spec.md，取舍记 .product/decisions.md。
