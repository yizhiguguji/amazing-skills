# 合成演练：续读

## 来源与范围

sources/request.md 是人为构造的抽象需求，不是真实客户确认：“想做个读书记录页，安静一点，每次打开知道接着读哪本，样式还没想好。” 无参考图、品牌或服务。

目标：一个人的浏览器阅读记录页；打开看到最近添加的书与下一步。MVP 为创建、查看、移除和本地保存，不包含账号、外部书目、跨设备同步或自动阅读统计。

## 推断与数据

标题为必填，下一步为选填；两者来自用户输入。记录 ID 由系统生成，条数按当前记录计算，顺序为最近新增在前。使用当前浏览器 localStorage 是合成演练决策，不是已确认的生产存储方案。首次进入无假数据、无假统计；存储异常明确告知且不清空输入。不自动覆盖损坏的历史数据。

## 页面

首屏先呈现书名列表与下一步，侧栏新增；手机单列。暖色纸面和衬线标题来自 design-evidence.json 的推断，不要求真实用户选样例。

## 可检查验收

- AC-01：空存储首次进入，不显示书目与数量，呈现添加入口；不发远程请求。
- AC-02：空标题提交保留输入并聚焦书名，显示恢复说明；有效提交新增记录、反馈成功并可刷新保留。
- AC-03：记录文字按文本显示，长标题和混排在 1440/390/320 宽度不导致整页横溢；仅合成浏览器数据用于检查。
- AC-04：移除指定记录后列表、计数和刷新状态一致，键盘可完成表单和操作。
- AC-05：存储失败不伪装成功，不清空输入；恢复存储后可重试；损坏数据不被覆盖。
- AC-06：组件预览与真实页面消费同一 tokens.css，浏览器计算样式一致；DESIGN.md/tokens 受现有设计锁保护。
- AC-07：组件预览表单的错误、有效反馈与禁用状态工作，桌面与小屏文字、焦点和间距符合包规范。

实际检查与未验证分别见 .product/verification.md；合成输入永不升级为真实用户访谈。
