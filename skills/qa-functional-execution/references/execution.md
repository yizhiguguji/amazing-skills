# 执行边界与证据

先核实际入口、可准备数据和观察方法。人工可以使用用户提供的记录，注明提供者和实际来源；AI不冒充人工执行身份。

真实网络profile须记录参数及生效验证。改变系统网络/锁屏/账号可能影响其他任务，只按当前授权与设备执行。恢复网络后核对请求结果和数据是否重复；不从提示文字推断持久化。

Web自动化参考适用的Playwright定位器、自动等待与业务断言；等待目标就绪，不能用固定sleep或networkidle代替完成条件。flaky区分应用时序、测试、环境和数据污染，修复不得削弱正确断言来变绿。持续失败有停止条件：保留问题及证据，继续独立项，不无限重试。

人工实机结果含构建标识、系统/设备、网络、起点、动作、观察、时间和媒体（如有）。截图先看有效画面，黑屏/浮层/过渡帧重新采集；树里存在控件不证明画面正常，首屏看不到不证明列表缺项。

失败、阻塞、延期、未执行分别记录。HTTP成功、按钮可点、文件存在、单元测试通过不能代替对应业务结果。无新媒体就明确无媒体，不虚构上传。
