# 明序 · Precise Console

## 方向与适用条件

为频繁扫描、表格和精确操作提供紧凑、清楚的合成起点；不默认暗色。 这是自建合成样例，不是已确认的用户设计，不代表外部品牌。无参考时可以从任务推导新方向，无需选用本样例。

## 颜色与排版

精确值由 tokens.css 单独管理。页面使用 --ds-bg，组件区域使用 --ds-surface，正文使用 --ds-fg，辅助文字使用 --ds-muted；主操作用 --ds-accent 与 --ds-accent-on，错误同时用 --ds-danger 和文字表达。正文与标题消费 --ds-font-body / --ds-font-display；包含中文回退，不加载远程字体。

## 密度与布局

把主要信息放在可扫描行列中，以表头、对齐和间距建立秩序；紧凑不牺牲操作尺寸。 使用 --ds-space 构成间距，--ds-content 限制内容宽度。小屏单列，长文本可换行，表格必要时局部横向滚动，页面整体不横溢。

## 组件与状态

按钮、输入、表格和空状态见 design-preview.html；焦点始终可见，禁用状态有明确文本与原生 disabled。错误保留输入并说明恢复方法，加载与空数据分开。样例数据明确为合成，不引入产品规则或统计。

## 动效与边界

本样例不需要动效。后续按实际任务选择，并尊重减少动态效果偏好。现有项目优先继承既有规范，不通过选择本包覆盖事实。

## 实现与验收

消费 tokens.css，按实际页面核对计算样式。查看桌面和小屏，检查中文混排、长文本、键盘焦点、表单错误及保存反馈。行为检查、视觉检查与未验证分别记录。预览只是组件样例，不代替实际产品验收；完成后使用现有设计锁保护规范与 tokens。
