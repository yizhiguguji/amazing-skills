# 统计与报告交付

正式执行首次失败保留；同轮重试通过只补充，独立新轮复测可给最新结论但列历史失败。最新修订没有运行记录就是未执行，旧修订成功不得继承。进行中轮次已保存结果可汇总，not-run不能覆盖历史执行。

范围总数只含当前承诺ready/deferred用例；proposed、retired及范围外不进分母，另列数量与理由。来源、需求修订和用例ID让数字可追溯。已执行定义、本期/历史、平台和环境口径必须注明。

实机、人工记录、浏览器模拟与synthetic-fixture分别统计。只有模拟结果时整体状态明确synthetic-only；脚本缺少真实设备证据不能报真实设备完成。实际运行时间来自记录并含时区，任务历时不等于有效工时。

报告先说范围与证据限定结论，再给执行进度、缺陷处理进度、主要风险、未覆盖/阻塞及下一步。缺陷状态来自保存记录或只读同步，注明来源时间；无缺陷清单不等于零缺陷。待产品确认、优化建议与覆盖缺口不计已确认缺陷。

表格/JSON/页面/图片来自同一明细，不一致先修口径而非手改数字。媒体检查可访问、完整且对应本轮操作；没有新增证据就注明。当前遗留与历史发现分开，已完成/撤回按明确关联归并，不按标题合并。
