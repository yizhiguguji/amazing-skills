# 开源参考与许可

本QA包为本地重写的独立技能，继承用户提供脱敏技能的专业约束。仅参考下列MIT项目的方法组织，没有将其Skill装成运行依赖，也不要求其他电脑联网读取它们。

- [qa-manual-istqb](https://github.com/fugazi/test-automation-skills-agents/tree/main/skills/qa-manual-istqb)：测试条件、黑盒方法、追踪及QA产物边界。不是ISTQB认证声明。
- [Currents Playwright Best Practices](https://github.com/currents-dev/playwright-best-practices-skill)：实际定位器、业务断言与等待条件；不自动导入其全测试类型清单。
- [Superpowers verification-before-completion](https://github.com/obra/superpowers/tree/main/skills/verification-before-completion)：完成声明需实际验证输出；不引入整套开发工作流或无条件审批。

具体复核commit与摘要见本目录sources.lock.json。保留MIT声明：[manual QA](licenses/qa-manual-qa-MIT.txt)、[Playwright](licenses/qa-playwright-MIT.txt)、[verification](licenses/qa-verification-MIT.txt)。这里只作独立参考及归属记录，原文未作为本地技能指令执行。

未复制非商业许可候选或许可未确认项目的内容。用户项目的设备、账号、服务、编号、分级和状态全部作为项目配置，不进入共享包。
