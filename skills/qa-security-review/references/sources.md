# 方法来源与适用边界

本技能原创文字采用本仓库MIT许可，以下仅为方法参考，不复制或捆绑标准正文，不宣称参考标准属于MIT，也不增加运行依赖。复核日期：2026-10-10；核心方法已写入本地引用，其他电脑不需要联网才能设计用例。

- [OWASP WSTG v4.2](https://wstg.owasp.org/v4.2/4-Web_Application_Security_Testing/)：选择与指定目标相关的身份、授权、会话、输入、错误、业务逻辑和客户端测试方法。引用具体章节；不直接遍历全部目录作为本期用例。
- [OWASP ASVS](https://owasp.org/www-project-application-security-verification-standard/)：帮助辨认可验证安全要求；仅项目明确采用且确认版本/条款/裁剪时才作为验收依据。不能凭技能自动宣称某等级合规。
- [OWASP MASVS](https://mas.owasp.org/MASVS/)：移动场景相关的存储、认证授权、网络、平台和隐私边界。仅涉及相应原生能力时使用，不把Web/H5模拟扩展成移动逆向专项。

项目批准的需求/安全基线决定预期；公开标准不替项目定义角色、密码长度、会话超时、限流阈值、掩码或加密实现。未知条款写待明确，参考条款与已采纳条款分列。
